## Correção de integração

A homologação full-chain identificou que a migration
`db33d016d6b4_link_bets_to_bankroll` dependia de `ALTER CONSTRAINT`, operação
não suportada pelo SQLite. Ela passou a usar o batch mode do Alembic, mantendo
compatibilidade com PostgreSQL e permitindo validar recuperação em banco
limpo.

## Implantação em staging

1. Copiar `.env.staging.example` para `.env.staging`.
2. Substituir todas as credenciais e tokens.
3. Executar `docker compose -f docker-compose.staging.yml up --build`.
4. Aguardar banco, migrations, scheduler e dashboard ficarem saudáveis.
5. Executar `python -m scripts.release_smoke`.
6. Registrar a aprovação humana antes de promover a versão.
